# 《法律问答系统(llm-wiki)》课程讲义

## 主线

```
理念(RAG vs llm-wiki) → 系统总览 → 环境安装
→ 知识图谱原理(图 / 本体论 / 法律本体 / Cypher)
→ 摄入(清洗切分 / 概念增强图谱 / 构建常见问题 / 落盘同步 / 图存储 / 代码精读)
→ 查询(意图路由 / 混合检索 / 多跳 / 反思 / 生成溯源 / 代码精读)
→ 记忆与服务化(双层记忆 / Web + 前端模块化)
→ 测试与评估
```

核心主张贯穿全程：**本系统不是 RAG**——把结构规整的法律文档在摄入期"编译"为可读可审计的法条级知识点 + 关联图谱
（`knowledge_graph.json` 为权威源，同步一份到 Neo4j 供图查询），查询期只做"定位知识点 + 让大模型依据给定知识点综合生成"；
向量仅参与召回打分（存于 Milvus），不做知识载体。`wiki/` 是**人读视图**，不参与检索、可随时重建。
